# 📖 Diccionario Español-Inglés: Reto de Lógica

Este repositorio contiene una solución al reto de lógica de programación #5, enfocado en el manejo de colecciones y flujos de control en **Java** ☕.

---

## 🎯 El Desafío

Crear un programa en `Java` que realice lo siguiente:

1.  Crear un diccionario **Español-Inglés**, que contenga al menos 20 palabras (con traducción).
2.  Utilizar un objeto **HashMap** para almacenar los pares de palabras.
3.  Escoger al azar 5 palabras en español del mini diccionario.
4.  Pedir al usuario que teclee la traducción al inglés de cada una de las palabras y comprobará si son correctas.
   
    **Resultados:** Al final debe mostrar por consola cuántas respuestas correctas e incorrectas tiene el usuario.

## 🛠️ Tecnologías se utilizaron

*   **JDK 17**
*   **IntelliJ IDEA**
*   Uso de clases base: `java.util.HashMap`, `java.util.Scanner` y `java.util.Collections`.
